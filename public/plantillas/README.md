# Directorio de Plantillas Públicas

Coloca aquí tus archivos de plantillas jurídicas (`.md`, `.txt`, `.docx` o `.json`).

La PWA de **Lex Corporativo** detectará y cargará automáticamente los archivos que agregues en este directorio (`/plantillas/`) para usarlos en el módulo de **Redactor & Plantillas**.
